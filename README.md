# Geospatial-Intro

## Deployment Instructions

This website is deployed using GitHub Pages. You can view the live website at:

https://darkvpnlord.github.io/Geospatial-Intro/

### Steps to enable GitHub Pages:

1. Go to the repository on GitHub
2. Click on "Settings"
3. Navigate to "Pages" in the left sidebar
4. Under "Source", select the "gh-pages" branch
5. Click "Save"
6. Wait a few minutes for the site to deploy

After following these steps, your website will be publicly accessible at the URL above.

## Local Development

To work on this website locally:

1. Clone the repository
2. Open the files in your preferred code editor
3. View the site by opening `index.html` in a web browser

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js for the interactive map
